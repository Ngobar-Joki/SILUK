🌐 Web Accessibility Widget

Demo implementasi fitur aksesibilitas untuk SILUK

📋 Cara Menggunakan Demo

  1. Lihat ikon aksesibilitas biru di pojok kiri bawah halaman
  2. Klik ikon untuk membuka panel pengaturan aksesibilitas
  3. Coba berbagai fitur seperti font size, highlight, dan dyslexia font
  4. Pengaturan akan tersimpan otomatis di localStorage
  5. Refresh halaman untuk melihat pengaturan tetap tersimpan

Tentang Fitur Aksesibilitas

Fitur aksesibilitas web ini dirancang untuk membantu pengguna dengan berbagai kebutuhan aksesibilitas. Widget ini mengikuti standar WCAG 2.1 dan menyediakan kontrol yang mudah digunakan untuk meningkatkan pengalaman pengguna.

Fitur Utama:

🔤 Kontrol Font Size

Ubah ukuran font dari 80% hingga 150% sesuai kebutuhan pengguna.

🌐 Multi-language

Dukungan Bahasa Indonesia, English, dan Bahasa Melayu.

🎯 Highlight Features

Sorot judul dan link untuk navigasi yang lebih mudah.

📖 Dyslexia-friendly

Font Comic Sans MS untuk membantu pengguna dengan disleksia.

📏 Spacing Controls

Atur letter spacing dan line height untuk kenyamanan membaca.

💾 Auto Save

Pengaturan tersimpan otomatis di localStorage dan database.

Informasi Teknis

Implementasi

Widget aksesibilitas ini dibangun menggunakan React TypeScript dengan dukungan:

  • React Context untuk state management
  • CSS Custom Properties untuk styling dinamis
  • LocalStorage untuk penyimpanan client-side
  • Laravel API untuk penyimpanan server-side
  • Tailwind CSS untuk styling responsive

Compliance

Fitur ini mengikuti standar aksesibilitas WCAG 2.1 Level AA dengan dukungan:

  • Keyboard navigation support
  • Screen reader compatibility
  • High contrast mode support
  • Focus indicators yang jelas
  • ARIA labels dan descriptions
